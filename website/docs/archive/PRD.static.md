# MASTERCAD Company Profile

Website berbahasa Indonesia untuk calon pelanggan jasa CAD engineering design. Pengunjung memahami layanan, melihat contoh lingkup pekerjaan, mempelajari proses, lalu menyiapkan brief konsultasi.

## MVP dan kriteria selesai

- Identitas MASTERCAD menggunakan logo pengguna dan amber #FFBF00.
- Beranda, tentang, layanan, contoh aplikasi desain, proses, FAQ, dan kontak dalam satu halaman responsif.
- Menu mobile, navigasi anchor, detail layanan, filter aplikasi desain, FAQ, dan pembuat brief berfungsi dengan keyboard.
- Nomor WhatsApp/email dapat diatur lewat konfigurasi. Tanpa kontak resmi, brief dapat disalin atau diunduh; halaman tidak mengklaim mengirim pesan.
- Tidak mengarang pelanggan, statistik perusahaan, alamat, sertifikasi, atau proyek yang pernah dikerjakan.
- Ilustrasi engineering dan contoh lingkup pekerjaan diberi konteks sebagai konsep.
- Pemeriksaan syntax, referensi aset, desktop, dan mobile sebelum serah terima.

## Keputusan dan asumsi

Proyek awal kosong, tidak ada framework yang harus dipertahankan. HTML, CSS, dan JavaScript modular tanpa dependensi dipilih agar ringan dan mudah dipelihara. Hosting privat Sites; source juga tersimpan lokal.

Daftar layanan adalah draft berdasarkan identitas CAD engineering pada logo, perlu disesuaikan pemilik. Kontak resmi, alamat, deskripsi usaha final, dan foto proyek nyata belum diberikan. Form tidak memakai backend dan tidak menyimpan data pengunjung ke server.
