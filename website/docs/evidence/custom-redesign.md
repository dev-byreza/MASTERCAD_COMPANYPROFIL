# Desain landing page mandiri — 5 Oktober 2026

Pengguna menolak tampilan sebelumnya dan meminta model landing page dibuat sendiri tanpa skill 21st. Pada revisi ini tidak ada pembacaan skill, pencarian katalog, pengambilan komponen, generate atau audit 21st.

Halaman beranda dan landing.css ditulis ulang. Hero charcoal dengan foto mekanikal besar, overlay untuk keterbacaan, logo putih, headline putih/amber dan CTA amber. Strip keahlian, panel layanan pilihan, profil studio, informasi karya dan CTA menggunakan warna utama `#FFBF00`. Layanan empat panel, karya unggulan foto/panel informasi, proses empat kolom, FAQ native details dan footer charcoal.

Beranda tidak mengimpor PortfolioGrid adaptasi katalog. Grid lama pada halaman portofolio sekunder tidak disentuh; evidence 21st dan amber sebelumnya tetap sebagai riwayat. Konten layanan/karya/proses/FAQ/settings dibaca dari snapshot Published seperti sebelumnya. Tidak menambah data usaha, mengirim pesan baru atau mengubah backend.

Pemeriksaan: TypeScript lulus; build produksi lulus. Preview visual desktop 1280 px, tablet 768 px dan mobile 360 px diperiksa. Ketiganya tidak menunjukkan overflow horizontal. Menu mobile membuka navigasi lalu menutup ketika menuju halaman kontak. FAQ dan tautan karya diperiksa di browser.
